# ITA0323 - Mobile Computing Laboratory

This repository contains the laboratory experiments, architectural overviews, simulation results, and application interfaces for **ITA0323 - Mobile Computing**.

---

## 📚 Experiments Index

| Experiment | Title / Topic | Contents |
| :--- | :--- | :--- |
| **Experiment 1** | **Evolution of Cellular Systems** | Analog cellular systems, digital GSM architectures, packet data transmission, and network evolution. |
| **Experiment 2** | **Mobile Application UI & Workflow** | End-to-end mobile user journey: authentication, train search, seat selection, booking, and digital e-ticketing. |
| **Experiment 3** | **GSM Network Switching Subsystem (NSS)** | NSS architectural layout, call routing procedures, subscriber registers (HLR/VLR), and termination. |
| **Experiment 4** | **Wireless Protocol Stack** | Physical, data link, network, transport, session/presentation, and application layers in mobile systems. |
| **Experiment 5** | **Location-Based Services (LBS)** | GPS & location permissions, nearby places discovery, filtering, and booking workflow. |
| **Experiment 6** | **Cellular Handoff / Handover Mechanism** | Signal strength comparison, handoff decision algorithms, and seamless inter-cell transition. |
| **Experiment 7** | **Network Performance & Signal Quality** | Dashboard monitoring, signal-to-noise ratio, call drop rates, data throughput, and analytical reporting. |
| **Experiment 8** | **Public Land Mobile Network (PLMN) & Roaming** | PLMN architectural components, visitor location tracking, coverage zones, and international roaming. |
| **Experiment 9** | **GSM Security & Cell Architectures** | Authentication vectors, ciphering mechanisms, micro/pico cell classifications, and roaming security. |
| **Experiment 10** | **Multiple Access Techniques** | Comparative analysis and working of FDMA, TDMA, CDMA, SDMA, and OFDMA multiplexing schemes. |
